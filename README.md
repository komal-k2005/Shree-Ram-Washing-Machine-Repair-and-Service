## 💻 Tech Stack & Design System

- **Markup & Layout:** HTML5 (single self-contained architecture)
- **CSS Framework:** Tailwind CSS (via CDN) + Custom Design System in `styles.css`
- **Typography:** Google Fonts (`Outfit` for display headings, `Inter` for body copy)
- **Icons:** Font Awesome 6.5 Free CDN
- **Animations:** AOS (Animate On Scroll) + GPU-accelerated CSS keyframes
- **Color Theme:**
  - Electric Blue (`#2563eb`)
  - Deep Indigo (`#1e1b4b`)
  - Vibrant Gold (`#facc15`)
  - WhatsApp Emerald (`#10b981`)
- **Interactive Form Engine:** Vanilla JavaScript ES6 (`script.js`) with live dynamic WhatsApp preview generator, interactive appliance chips, and area pills.

## 🚀 How to Run or Deploy

### Local Preview
Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari), or serve with any static web server:
```bash
# Python 3
python -m http.server 8000

# or Node.js npx
npx serve
```

### Production Deployment
This project is 100% static and ready for instant deployment to:
- **GitHub Pages**
- **Netlify**
- **Vercel**
- **Cloudflare Pages**
- **cPanel / Apache / Nginx** hosting

Simply point the document root to this repository folder.
